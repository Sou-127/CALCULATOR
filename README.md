# CALCULATOR
A simple and responsive Calculator Web Application built using HTML, CSS, and JavaScript.
This project performs basic arithmetic operations and demonstrates core front-end web development concepts.

# Project Overview
The Calculator allows users to perform basic mathematical calculations such as addition, subtraction, multiplication,division and percentage.It features a clean user interface and real-time calculation handling using JavaScript.

# Features
* Addition
* Subtraction
* Multiplication
* Division
* Percentage
* Clear / Reset functionality
* Responsive design for different screen sizes
* Instant result display

# Technologies Used
* **HTML:** Structure of the calculator
* **CSS:** Styling and layout
* **JavaScript:** Logic and calculation handling

# Learning Outcomes
* DOM manipulation using JavaScript
* Event handling (button clicks)
* Managing user input and output
* Building a responsive UI with CSS
* Implementing basic logic for calculations
